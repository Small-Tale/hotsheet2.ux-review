[docs/01-architecture.md](../docs/01-architecture.md#12-cross-platform-contract): write
`review.json` conforming to `spec/review-bundle.schema.json`, compose the same intake ticket, and
use the same Hot Sheet discovery and CLI contract.

host's file manager and uses its path format ([docs/06-annotation-editor.md](../docs/06-annotation-editor.md#673-showing-a-captures-file) §6.7.3, `HS2-ZBZNRS`).

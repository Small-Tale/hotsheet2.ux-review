# 01 — Architecture

Status: foundation (`HS2-3ZSBZ9`).

## 1.1 Repository layout

```
spec/        platform-neutral contract (JSON Schema + examples), shared by every client
macos/       macOS client (Swift 6, SwiftPM + XcodeGen)
linux/       future Linux client (HS2-DXWATE)
windows/     future Windows client (HS2-DEP1TW)
docs/        requirements (source of truth)
scripts/     repo gate and tooling
```

## 1.2 Cross-platform contract

Platform clients share **formats and behavior, not code**:

- **Review bundle**: every client writes `review.json` conforming to
  `spec/review-bundle.schema.json` ([02-review-bundle.md](02-review-bundle.md)).
- **Ticket body**: every client composes the same intake ticket structure
  ([03-hotsheet-integration.md](03-hotsheet-integration.md) §3.3).
- **Hot Sheet integration**: every client uses the same store discovery order and the same CLI
  invocation contract (§3.1–3.2).

Examples in `spec/examples/` are validated against the schema by `scripts/check.sh`. Each
client's tests must decode them, and the macOS tests also re-encode them losslessly.

## 1.3 macOS client

- **`macos/Package.swift`**: SwiftPM package `UXReviewKit`, the core with no AppKit dependency.
  It holds the model (`Model/`), validation, ticket composition (`Tickets/`), and Hot Sheet
  integration (`HotSheet/`). Run its tests with `swift test`.
- **`macos/project.yml`**: XcodeGen spec for `UXReview.app`. This is a menu-bar-only agent app
  (`LSUIElement`) built with SwiftUI `MenuBarExtra`. It depends on the local package. The
  `.xcodeproj` is generated by `scripts/macos-project.sh` and is not committed.
- **Minimum OS**: macOS 14, for ScreenCaptureKit's `SCScreenshotManager`.
- **Bundle id**: `com.smalltale.uxreview`.
- **Headless smoke mode**: `UXReview --status [--project <dir>]` prints the Hot Sheet status as
  JSON and exits with 0 when ready, 3 otherwise.
- **Capture** (`App/Sources/Capture/`): ScreenCaptureKit backend, region/window picker overlays,
  countdown HUD, and `CaptureCoordinator`. Pure parts (requests, region math, window selection,
  context, draft store, `--capture` parsing) live in `UXReviewKit` (`Capture/`, `Review/`).
  See [04-capture.md](04-capture.md).
- **Headless modes**: `UXReview --capture …`, `--settings …`, and `--render-ui-previews DIR`
  ([04-capture.md](04-capture.md) §4.11, [05-start-and-settings.md](05-start-and-settings.md) §5.5).
- **Settings**: stored in the app's defaults domain (or `UXREVIEW_DEFAULTS_SUITE`): the project
  folder (`projectDirectory`, overridable with `--project`) and capture settings
  (`captureSettings`: default request + global hotkey). The hotkey is registered with Carbon
  `RegisterEventHotKey` (`App/Sources/Settings/`). See [05-start-and-settings.md](05-start-and-settings.md).

## 1.4 Gates

`scripts/check.sh` runs, in order:

1. `swiftformat --lint`
2. `swiftlint --strict`
3. ajv validation of `spec/examples/*.json`
4. `swift test` with `UXREVIEW_REQUIRE_HOTSHEET=1`, so a missing `hotsheet-cli` fails instead of
   skipping the end-to-end test
5. the XcodeGen + `xcodebuild` app build
6. the app smoke run against a throwaway Hot Sheet store
7. `scripts/app-e2e.sh`, which drives the built app's headless capture and preview modes

Set `SKIP_APP=1` to skip the app build. Long steps are time-boxed when coreutils `timeout` is
available.

SwiftFormat owns layout, including trailing commas. SwiftLint's `trailing_comma` rule is
disabled to avoid conflicts. SwiftFormat's `hoistTry` rule is disabled because it rewrites
`#expect(try …)` into invalid code.
